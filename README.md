# Thuong Le Van — SEO Portfolio

A responsive portfolio featuring SEO case studies for FOX SCORE, Insurance HQ, DTCGroup, Wingolf, and CenforceAU.

## Preview locally

Open `index.html` in a browser. Project case studies are in `projects/`.

## Structure

- `css/` — shared and project-specific styles
- `js/` — navigation, language switching, contact form, and case study interactions
- `assets/` — portfolio images and favicon
- `output/pdf/` — SEO automation process document
