01 · LEGACY SITE DIAGNOSIS

Several connected failures made the old site hard to trust

Historical review · Wingolf issue tracker

The problems were not limited to page titles. URL behavior, indexability, language routing, booking flows and account access affected both search discovery and the customer journey.

URL

Unstable URL patterns

Booking URLs exposed search and filter parameters. Duplicate slash paths also returned a successful page response instead of consistently resolving to one clean URL.

SEO impact · Duplicate or low-value URL variants complicate crawling and canonical signals.
AUTH

Login and booking friction

The legacy account/login flow created a user-facing blocker during the booking journey, alongside static or inconsistent booking paths.

Source · Login flow is based on my project-side observation; it is not a separately quantified row in the saved tracker.
LANG

Language routing did not stay aligned

Localized URLs, language switching and hreflang relationships were inconsistent across the Vietnamese, English, Chinese and Korean experiences.

SEO impact · Search engines and visitors could receive mismatched language versions.
CRAWL

Technical discovery gaps

The review flagged missing robots.txt and XML sitemap files, plus broken image links and rendering or interaction defects that needed developer attention.

SEO impact · Weaker crawl guidance and an incomplete page experience.

THE PROJECT DECISION

Move from repeated patches to a planned rebuild

After the legacy issues remained unresolved through the available development work, I recommended moving forward with a new website plan. The aim was to address URL rules, language structure, booking journeys and SEO requirements in the design and build brief from the start.

CRITICAL · INDEXABILITY01 / 05

Default booking filters created crawlable URL variants

Observed Tee-time pages exposed time, price and date parameters even before a visitor applied filters. Search Console reported the captured URL as not indexed.

Why it matteredDuplicate URL variants and missing canonical signals could dilute crawl focus and prevent important course pages from being indexed.
Reported directionKeep default state on a clean URL, process filter values without unnecessary URL variants, and use a canonical URL for the indexable course page.
CRITICAL · URL CANONICALIZATION02 / 05

Malformed paths still returned a successful page

Observed The saved redirect trace showed a multi-slash URL returning HTTP 200, creating another path to the same site experience.

Why it matteredSearch engines can treat alternate paths as separate URLs, multiplying duplicate pages across the site.
Reported directionNormalize repeated slashes and permanently redirect alternate forms to the single preferred URL.
CRITICAL · INTERNATIONAL SEO03 / 05

Language pages were not connected as equivalent versions

Observed The tracker flagged incorrect language URL structure, missing hreflang and a language switcher that sent visitors to the language home page instead of the equivalent page.

Why it matteredVisitors lost the content they were reading, while search engines lacked consistent signals for localized pages.
Reported directionUse language folders, map translated page equivalents, and connect them with reciprocal hreflang and page-level language switching.
CRITICAL · BOOKING INTEGRITY04 / 05

Booking paths mixed transactional flows with indexable pages

Observed The tracker recorded many static booking URLs as indexable. I also observed login friction in the legacy booking journey.

Why it matteredSearch could discover thin transaction pages, while account and booking friction interrupted the path to conversion. The tracker also recorded a critical booking-price integrity concern.
Reported directionConsolidate checkout into a controlled transaction flow, set appropriate index rules, map old booking URLs, and validate account access and price integrity with development.

Sensitive booking-integrity reproduction details are intentionally omitted from this public case study.

HIGH · CRAWL & PAGE QUALITY05 / 05

Search guidance and page behavior needed a rebuild checklist

Observed The review logged missing robots.txt and XML sitemap, image URLs returning 404, a broken image presentation state, and a “show more” control that navigated away.

Why it matteredCrawlers lacked useful discovery guidance, while visible interaction and image failures weakened the course page experience.
Reported directionPublish crawl files, repair image paths and fallback display, and expand descriptions in place without interrupting booking.
